## Events for external systems (sprint 6.4)

Usage and limit events leave Pandokos by signed webhook, or are pulled over the API, in CloudEvents 1.0
([events guide](../operations/events.md), [event reference](../reference/events.md)).

- **Events.** Nine types: `usage.recorded`, `limit.threshold_reached`, `limit.exhausted` (a tenant's log) and
  `tenant.deletion_requested`, `tenant.deletion_cancelled`, `tenant.deleted`, `kek.version_activated`,
  `kek.version_retired` (the platform's log), each with a published JSON Schema in `docs/reference/events/`. The
  database writes them in the transaction of the fact.
- **Destinations.** A tenant registers up to 8 signed webhooks (Standard Webhooks headers, a signing secret shown
  once, rotation with an overlap), tests them, rewinds them, and replays dead letters. Delivery is at least once,
  with backoff and a dead-letter state. An example receiver is in `examples/webhook-receiver`.
- **Pull.** `pandokos event export` and `pandokos platform-event export`; the sequence of the last line is the
  cursor.
- **The external reference** of a tenant, set by the platform, is carried by every event.
- **Five permissions:** `event_destination:read`, `event_destination:write`, `event_destination:delete`,
  `event:read`, `platform_event:read` ([permissions](../reference/permissions.md)).
- **Twelve operations** under the tag `events` and the commands `event-destination`, `event`, `platform-event`
  and `event schema`; the document has 179 operations.
- **Nine configuration keys**, `events.*` ([configuration reference](../operations/configuration.md)).
- **Seven instruments** (`pandokos.events.*`) and six log lines.

### Upgrade notes

- Migration `0017_events` is applied by `pandokos migrate`. **Events start with it: nothing is produced for the
  past.** It revokes nothing.
- **The cost on the ledger's insert:** each usage record also writes an event. On the development machine of the
  sprint a batch of 500 records took a median 108.7 ms without the trigger and 145.5 ms with it (ratio 1.34;
  `TestOutboxWriteCost`, `make bench`); measure on your hardware.
- **The bound of EVT-03:** events are kept for `events.retention` (168 hours by default), delivered or not; an
  event an enabled destination had not received by then is removed and counted. Events of a tenant not delivered
  when its deletion begins are removed with it.
- Webhooks leave from the worker role through the egress guard; hosts that are `http` or private must be listed in
  `events.webhook.private_hosts`.
